## 1. 实验概览

### 1.1 实验目标

实验比较 BrandBrew 与 AI design-agent 系统 Lovart 在品牌视觉识别（Brand Visual Identity，BVI）设计任务中的表现，主要回答以下问题：

- BrandBrew 是否能为设计师提供更强的创造力支持，包括结果满意度、想法数量、想法多样性和想法创造性？

- BrandBrew 是否能产生视觉上更一致的 Logo–Mockup 组合？

- BrandBrew 是否能提升设计师感知到的创作控制力，以及其自述的设计方向实现程度与偏离恢复能力？

### 1.2 实验设计

- **实验类型：** 被试内对照实验。

- **参与者：** 12 名专业或具有较丰富实践经验的视觉设计师。

- **实验系统：** BrandBrew 和 Lovart。

- **实验任务：** 每位参与者完成同一个 BVI 设计任务的两个实验 Block；每个 Block 使用一个系统和一份 Brief 材料版本。

- **任务阶段：** Logo 设计 → Mockup 应用。

- **实验方法：** 操作日志、屏幕录制、Think-aloud、问卷、专家评分和半结构化访谈。

### 1.3 系统顺序与 Brief 分配

12 名参与者平均分配到以下四种组合，每种组合 3 人：

| 组合 | 第一个 Block | 第二个 Block |
|---|---|---|
| G1 | BrandBrew + Brief A | Lovart + Brief B |
| G2 | BrandBrew + Brief B | Lovart + Brief A |
| G3 | Lovart + Brief A | BrandBrew + Brief B |
| G4 | Lovart + Brief B | BrandBrew + Brief A |

### 1.4 实验任务

本研究将任务操作性定义为：参与者根据标准化 Brand Brief 形成视觉方向，完成 Logo，并将 Logo 与主要视觉决策延伸到一个应用 Mockup，最终确认一组 Logo–Mockup 结果。Brief A 与 Brief B 是该共同 BVI 任务的两个平行材料版本，而不是两个独立任务。两份材料的品牌内容、受众和应用媒介不同，但任务目标、阶段、时间限制、约束数量和交付结构保持匹配。

#### Brief A：数字场景
为面向老年用户的电子商务服务设计品牌视觉识别：

- 阶段一：设计 Logo；
- 阶段二：将 Logo 和其他视觉元素应用到网站或移动端界面 Mockup。

#### Brief B：实体场景
为面向大学生的健康补充剂品牌设计品牌视觉识别：

- 阶段一：设计 Logo；
- 阶段二：将 Logo 和其他视觉元素应用到包装 Mockup。

两个 Brief 在以下方面进行匹配：

- 信息长度
- 设计约束数量
- 目标受众描述粒度
- 必须呈现的品牌内容
- Logo 和 Mockup 的交付要求

数字与实体场景的差异不是要验证的独立变量，因此在分析中将 Brief 作为平衡因素和敏感性分析变量处理，而不解释为独立实验效应。

## 2. 实验流程

### 2.1 时长说明

实验主体约 91 分钟。每个系统使用后立即填写 CSI 的 12 道系统体验评分；两个实验 Block 均完成后，填写一次共同任务权重比较，再进行半结构化访谈。建议实际预留约 95 分钟：

| 环节         | 内容                          |          时长 |
| ---------- | --------------------------- | ----------: |
| 实验介绍       | 知情同意、实验说明、背景问卷              |        5 分钟 |
| Block 1 教学 | 第一个系统的标准化教学与练习              |        5 分钟 |
| Block 1 任务 | 阅读 Brief、Logo、Mockup、Think-aloud |       20 分钟 |
| Block 1 后测 | CSI 系统体验评分（12 题）            |        4 分钟 |
| 休息         |                             |       10 分钟 |
| Block 2 教学 | 第二个系统的标准化教学与练习              |        5 分钟 |
| Block 2 任务 | 阅读 Brief、Logo、Mockup、Think-aloud |       20 分钟 |
| Block 2 后测 | CSI 系统体验评分（12 题）            |        4 分钟 |
| 共同任务权重     | CSI 维度权重比较（15 组，仅一次）          |        3 分钟 |
| 半结构化访谈     | 主观控制、方向实现感、系统比较、Brief 难度与改进建议 |       15 分钟 |
| **总计**     |                             | **约 91 分钟** |

### 2.3 开场说明

> 感谢你参加本次研究。我们希望了解不同 AI 设计系统如何支持设计师完成品牌视觉识别任务。本实验评估的是系统，而不是你的个人设计能力。请按照你平时的设计方式完成任务。操作过程中，请尽量说出你正在关注什么、为什么做出某个选择、你希望系统产生什么变化，以及结果是否符合你的预期。实验会记录屏幕、操作和语音；数据将以匿名方式分析。除非系统出现技术故障，研究人员不会替你决定设计方向。

确认参与者：

- 已阅读并签署知情同意
- 同意录屏、录音和匿名引用

### 2.4 背景问卷

参与者填写“附录 A：实验前背景问卷”。

### 2.5 Block 1

#### 第一步：系统教学与练习（5 分钟）

教学内容仅覆盖完成任务所必需的功能。两个系统的教学时长和信息量应尽量一致。

BrandBrew 教学：
- 阅读和确认 Brand Brief
- 查看 visual concept、color、typography、logo 和 art style 的候选方案
- 选择或保存候选方案
- 使用 DirectMerge 表达元素之间的影响关系
- 生成和选择 Logo
- 生成 Mockup
- 撤销、恢复或重新生成
- 选择最终结果

Lovart 教学：

- 输入或确认 Brand Brief
- 向 Agent 表达设计方向
- 上传、引用或选择视觉素材
- 要求生成 Logo
- 要求生成 Mockup
- 修改或重新生成
- 选择并保存最终结果

练习使用与正式任务无关的示例，练习结果不进入分析。


#### 第二步：正式任务开始（20 分钟）

- 向参与者展示本 Block 分配的 Brief 材料版本；
- 开始 20 分钟统一计时，Brief 阅读时间包含在任务时限内；
- 参与者在 Logo 与 Mockup 两个阶段持续 Think-aloud；
- 不要求参与者在任务开始前预先固定设计方向。


#### 第三步：Logo 阶段

- Logo 阶段最多 15 分钟
- 参与者认为获得满意 Logo 后，可以提前进入 Mockup 阶段
- 主持人记录首次生成、首次满意候选和最终 Logo 的时间点

#### 第四步：Mockup 阶段

- 使用任务剩余时间完成 Mockup
- Mockup 应使用或延续 Logo 阶段的主要视觉决策
- 参与者需选择一个最终 Mockup
- 主持人记录参与者是否在时间限制内获得满意结果

#### 第五步：任务结束

参与者需明确标记：
- 最终 Logo
- 最终 Mockup
- 所有“有意义且不同”的候选想法
- 是否对结果满意
- 是否因为时间到而被迫停止

#### 第六步：CSI 系统体验评分

参与者立即填写“附录 B：CSI 中文问卷”的 B1 系统体验评分，共 12 题。此时不填写 B2 共同任务权重比较。研究者可以根据 Think-aloud、操作日志和屏幕录像记录关键事件，但不再要求参与者填写额外的系统后测问卷。

### 2.6 休息

休息期间不展示下一个 Brief，也不讨论第二个系统的预期表现。研究人员检查第一个 Block 的数据是否保存完整，但不向参与者反馈其表现。

### 2.7 Block 2

Block 2 使用第二个系统和另一个 Brief，重复以下步骤：

1. 五分钟系统教学与中性练习；
2. 阅读 Brief，并开始 20 分钟统一计时；
3. 完成 Logo；
4. 完成 Mockup；
5. 标记最终结果和候选想法；
6. 填写 CSI 的 12 道系统体验评分，不填写权重比较。

### 2.8 共同任务权重比较

参与者完成两个实验 Block 后，填写“附录 B：CSI 中文问卷”的 B2 共同任务权重比较，共 15 组二选一且仅填写一次。主持人必须说明，两份 Brief 是同一 BVI 设计任务的两个材料版本，权重比较针对完成这类任务时哪些方面更重要，而不针对某个系统或某份 Brief。

### 2.9 半结构化访谈

参与者完成共同任务权重比较后，研究者按照“附录 D：半结构化访谈提纲”进行访谈。系统比较、主观控制、设计方向实现感、偏离与恢复事件、真实项目选择和 Brief 难度均在访谈中记录，不再单独发放系统对比问卷。

### 2.10 实验结束

主持人：

- 确认所有文件使用匿名编号；

- 检查两个系统的最终结果和候选集合；

- 记录技术故障及受影响时间；

- 询问参与者是否同意后续联系；

- 向参与者说明实验目的并完成报酬流程。

## 3. 数据记录规范

### 3.1 自动或人工记录的行为数据

| 数据 | 定义 |
|---|---|
| 任务完成时间 | 从正式计时开始到参与者确认最终 Logo–Mockup 组合 |
| Logo 阶段时间 | 从正式计时开始到进入 Mockup 阶段 |
| 首次成功操作时间 | 从开始使用系统到首次完成与任务相关且产生预期反馈的操作 |
| 首次满意候选时间 | 从正式计时开始到参与者第一次明确表示候选结果可以接受 |
| 想法数量 | 参与者主动保存或标记为“有意义且彼此不同”的候选数量 |
| 生成次数 | 系统实际产生新候选结果的次数 |
| 修正迭代次数 | 参与者因结果不符合意图而进行的修改或重新生成次数 |
| 撤销次数 | 撤销或回退到先前状态的次数 |
| 无效操作 | 未产生预期系统响应或因不理解交互而失败的操作 |
| 求助次数 | 超出标准教学后，参与者主动向主持人请求操作帮助的次数 |
| 教学提醒次数 | 主持人根据预先规定的帮助规则给出的提醒次数 |
| 是否超时 | 在时间限制内未确认满意结果时记为 1 |

首次成功操作时间、无效操作、求助次数和教学提醒次数用于检查实验执行是否一致，并辅助解释异常案例；本研究不将其单独作为研究结果或评价维度。

### 3.2 两个系统的共同事件编码

两个系统的底层操作不同，因此不能直接把“点击次数”当作等价指标。屏幕录像应按照共同语义编码：

- 表达新设计方向；

- 选择候选方案；

- 指定元素关系；

- 请求生成；

- 请求局部修改；

- 请求整体修改；

- 放弃当前方向；

- 恢复先前方案；

- 确认最终结果；

- 请求研究人员帮助。

### 3.3 研究目标与主要证据来源

| 研究目标 | 主要证据 | 补充与解释性证据 |
|---|---|---|
| 创造力支持 | CSI | 候选数量与生成日志、专家创造性和候选多样性评分 |
| Logo–Mockup 视觉一致性 | 专家盲评 | 最终产物、候选集合和屏幕录像中的异常案例 |
| 主观控制与设计方向实现 | 半结构化访谈中的具体事件 | 修正迭代、撤销、局部修改日志以及对应的屏幕录像片段 |

不同证据不合并为单一总分。创造力相关访谈问题不再作为固定访谈内容；创造力结论由 CSI、行为日志和专家评分共同支持。视觉一致性的主要结论以专家盲评为依据。控制相关结论必须建立在参与者的主观描述及其指认的具体操作事件上，并尽可能与屏幕录像或日志核对；不得将这些材料解释为最终结果与任务前意图的客观一致性。

### 3.4 方法边界与敏感性检查

- 两份 Brief 的等价性是实验设计中的匹配假设，而不是已经得到验证的结论。研究者应结合第 5 个访谈问题、完成率、阶段用时和超时情况检查 Brief 难度是否失衡。
- 若 Brief A 与 Brief B 出现明显难度差异，应在结果中报告，并将 Brief 与 Block 顺序纳入敏感性分析，而不能继续无条件声称材料完全等价。
- 参与者在任务结束后报告的设计方向实现程度属于主观回顾，可能受到记忆偏差和结果合理化影响。因此，该证据只用于解释感知控制与偏离恢复，不能作为独立验证最终结果是否匹配任务前方向的依据。
- 共同任务权重在第二个 Block 后测量，可能存在近因效应。系统顺序应保持反平衡，并探索权重是否随最后使用的系统发生系统性变化。

# 附录 B：CSI 中文问卷

CSI 原量表包含六个维度、每个维度两个评分题，以及 15 组维度权重比较。每道评分题使用 0–10 分：

- 0 = 非常不同意
- 5 = 中立
- 10 = 非常同意

正式发放时，评分与权重分开施测：

- 每个系统使用后只填写一次 12 道系统体验评分，共填写两次；

- 两个实验 Block 全部完成后，只填写一次 15 组共同任务权重比较；

- 不向参与者显示维度名称；

- 不按维度相邻排列题目；

- 对题目顺序进行随机化；

- Collaboration 题允许选择“不适用”；

- 不随意删减维度，否则不能直接把结果称为标准 CSI。

CSI 的结构和计分依据来自 Cherry 与 Latulipe 的原始论文：[Quantifying the Creativity Support of Digital Tools through the Creativity Support Index](https://doi.org/10.1145/2617588)。

## B1. 系统体验评分（每个系统后填写）

提示语：

> 请根据你刚刚使用这个系统完成当前 Brief 材料版本时的体验，对以下陈述进行评分。

### 探索（Exploration）

1. 使用这个系统时，我能够轻松探索许多不同的想法、选项、设计或结果。

2. 这个系统能够帮助我记录和追踪不同的想法、结果或可能性。

### 表达（Expressiveness）

3. 使用这个系统完成任务时，我能够充分发挥创造力。

4. 这个系统使我能够充分表达自己的设计想法。

### 沉浸（Immersion）

5. 我的注意力能够完全投入设计活动，以至于不再注意自己正在使用的系统。

6. 我非常投入这项设计活动，以至于忘记了系统本身的存在。

### 愉悦（Enjoyment）

7. 我愿意在日常设计工作中经常使用这个系统。

8. 我享受使用这个系统的过程。

### 结果值得投入（Results Worth Effort）

9. 我对通过这个系统获得的结果感到满意。

10. 使用这个系统得到的结果值得我为此付出的努力。

### 协作（Collaboration）

11. 这个系统使其他人能够轻松地与我一起工作。

12. 在这个系统中，与其他人分享想法和设计非常容易。

本实验为个人任务；如果参与者认为协作不适用于当前任务，可以选择“不适用”。

## B2. 共同任务维度权重比较（两个 Block 后仅填写一次）

## B3. CSI 计分

对每个维度：

1. 将该维度的两个评分题相加，得到范围为 0–20 的维度小计；协作题的“不适用”在相加前转换为 0；
2. 统计该维度在 15 组比较中被选择的次数，得到范围为 0–5 的维度权重；
3. 将维度小计乘以维度权重；
4. 将六个维度的加权分相加；
5. 总和除以 3，得到 0–100 的 CSI 总分。

每次比较只选择一个维度，因此六项维度权重之和必须等于 15；不满足该条件的记录应标记为数据错误并核查。

每位参与者只产生一组共同任务权重。该权重向量通过参与者编号分别连接到 BrandBrew 与 Lovart 的系统体验评分，并原样应用于两个 condition。不得为两个系统计算不同权重，也不得在应用权重前跨参与者平均权重。

每位参与者、每个系统的计算公式为：

```text
CSI_system = Σ(系统维度小计 × 参与者共同维度权重) / 3
```

除加权 CSI 总分外，同时报告六个未加权维度小计。共同权重是否随最后使用的系统而变化，只作为近因效应的探索性检查，不解释为系统专属权重。

# 附录 C：专家盲评问卷

## C1. 评分设置

- 由 3 名具有品牌设计经验的专家独立评分；

- 隐藏参与者编号、系统名称和界面信息；

- 随机呈现输出顺序；

- 每份材料包含 Brand Brief、最终 Logo 和最终 Mockup；

- 评估想法多样性时，提供该 condition 下所有被标记为有意义的候选集合。

所有评分使用 7 点量表：

- 1 = 非常差或完全不符合；
- 4 = 中等；
- 7 = 非常好或完全符合。

## C2. 最终结果质量

1. **Brief alignment：** 最终结果符合 Brand Brief。

2. **Logo quality：** Logo 在构图、识别性和完成度方面表现良好。

3. **Mockup quality：** Mockup 在呈现、真实感和完成度方面表现良好。

4. **Aesthetic quality：** 整体结果具有较高的视觉美感。

5. **Appropriateness：** 设计适合目标品牌、受众和应用场景。

6. **Production readiness：** 结果接近可以进入真实项目后续开发的状态。

## C3. 创造性

7. **Novelty：** 设计方向具有原创性，不是常见方案的直接复制。

8. **Conceptual creativity：** 视觉形式对品牌概念进行了有创造性的转化。

9. **Overall creativity：** 综合新颖性与适切性，该结果具有较高创造性。

## C4. 视觉一致性

10. **Logo–Mockup coherence：** Logo 与 Mockup 属于同一个清晰的视觉系统。

11. **Color consistency：** Logo 与 Mockup 的颜色使用协调一致。

12. **Typography consistency：** 字体和文字风格在不同产物之间协调一致。

13. **Form consistency：** 图形语言、形状和构图原则保持一致。

14. **Art-style consistency：** 整体艺术风格在 Logo 与 Mockup 之间得到延续。

15. **Overall BVI consistency：** 最终产物共同形成了统一的品牌视觉方向。

## C5. 候选想法多样性

针对同一参与者在一个 condition 中保存的全部候选方案评分：

16. 候选方案在核心概念或隐喻方面具有多样性。

17. 候选方案在视觉形式和构图方面具有多样性。

18. 候选方案在颜色、字体或艺术风格方面具有多样性。

19. 综合而言，该候选集合覆盖了多个有意义且彼此不同的设计方向。
